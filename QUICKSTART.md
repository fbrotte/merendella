# ⚡ Démarrage ultra-rapide

## 🚀 En 30 secondes

```bash
# 1. Installer les dépendances
npm install

# 2. Lancer le serveur
npm run dev
```

## 🌐 Accès

Ouvrez votre navigateur sur **http://localhost:5173/**

## 🎬 Utilisation

1. **Page d'accueil** : Regardez l'effet de frappe, puis cliquez sur "Démarrer la revue"
2. **Écran principal** :
   - Gauche = Conversation IA
   - Droite = Email/Trello
3. **Interactions** :
   - `Générer réponse IA` → Attend 2s → Réponse apparaît
   - `Modifier via IA` → Reformule légèrement
   - `Envoyer` → Toast + Email suivant
   - `Voir carte Trello` → Bascule vers Trello
   - `Retour au mail` → Revient à l'email

## 🎯 C'est un prototype !

Toutes les interactions sont **simulées**. Aucune vraie IA, aucun vrai email.
Le but est de visualiser l'interface et le flux de travail.
